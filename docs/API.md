# Frappe Sign: API reference

Generated by `scripts/make_api_docs.py` from the whitelisted functions in `frappe_sign/api/`. Do not edit by hand.

Call a function at `/api/method/frappe_sign.api.<module>.<function>`. Staff calls need a logged-in session (cookie and CSRF token, or an API key). The `code` of a failed call is stable: switch on it, never on the message. Codes are in `frappe_sign/exceptions.py`.

## Guest API

Signers, no account. Every call is POST, rate limited, and carries the link token (`open`, OTP calls) or the `X-Sign-Session` header. Failures return a stable `code`.

### `open`

`open(token: str) -> dict`

POST, guest, rate limit 30 per MINUTE s.

### `request_otp`

`request_otp(token: str, channel: str='Email') -> dict`

POST, guest, rate limit 5 per HOUR s.

### `verify_otp`

`verify_otp(token: str, code: str) -> dict`

POST, guest, rate limit 10 per 10 * MINUTE s.

### `state`

`state() -> dict`

POST, guest, rate limit 60 per MINUTE s.

### `get_pdf`

`get_pdf() -> Response`

POST, guest, rate limit 30 per MINUTE s.

## Public API

Anyone. Rate limited. Returns no document content.

### `verify`

`verify(file: str | None=None, envelope: str | None=None) -> dict`

POST, guest, rate limit 10 per 60 s.

`file` is a multipart upload or a base64 string; `envelope` an envelope ID.

## Portal API
