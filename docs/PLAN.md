# Frappe Sign: Build Plan

About 8 weeks to a live pilot and 11 weeks to v1, assuming one backend and one frontend developer (or one developer working with Claude Code). Each phase ends at a **gate** that must pass before the next phase starts. Task IDs (`P1.4`) are referenced in commits and PRs.

```mermaid
flowchart TB
    P0["Phase 0 Foundations<br/>1 week"] --> G0{{"Gate 0: CI green on v16.0.0 and version-16, with and without ERPNext"}}
    G0 --> P1["Phase 1 Core signing<br/>4 weeks"] --> G1{{"Gate 1: sealed output validates in pyHanko and Adobe; concurrency test passes"}}
    G1 --> P2["Phase 2 ERPNext<br/>3 weeks"] --> G2{{"Gate 2: signed Quotation creates draft Sales Order end to end; pilot live"}}
    G2 --> P3["Phase 3 Hardening<br/>3 weeks"] --> G3{{"Gate 3: four pilot weeks, no lost or unsealed envelope; v1 released"}}
    G3 --> P4["Phase 4 Later"]
```

Conventions for every task:

- Tests first for `pdf/` and `services/` code.
- Done means: code, tests, types pass, lint passes, docs updated if behaviour changed.
- One PR per task or tightly related pair.
